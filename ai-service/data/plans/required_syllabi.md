# Required Course Syllabi

Courses whose syllabus must be collected and run through the syllabus
skill-extraction pipeline, to build the **course → skill map** that M2 joins
against a student's transcript.

> Regenerated by `python -m careercompass.cli.build_syllabus_list`. Every
> checkbox is set from disk — `data/extracted/syllabi/` and `data/syllabi/`
> — so ticking one by hand will not survive a rebuild. Drop the PDF into
> `data/syllabi/` and the box ticks itself.

## Code equivalences published by the syllabi

Several syllabus documents print both numbering schemes side by side, in the
course-code line and in prerequisites. This is the old → new mapping stated
by the department itself, so the canonical course id does not have to be
guessed from course names — it can be harvested as more syllabi arrive.

| New code | Old code | Seen in | Line |
|---|---|---|---|
| `A0412101` | `0432101` | `operating_systems.pdf` | A0412101 (0432101) - Data |
| `A0413301` | `0433301` | `operating_systems.pdf` | Course Title Operating Systems Course No. A0413301 (0433301) |

## Code collisions

The same course number means **different courses** in different plans. Any
course → skill map keyed on a plan's course code will join a student to the
wrong skills for every entry below.

## Notes

1. **Course codes are per-plan, not per-course.** The same course carries
   different codes across editions, *and* the same code can mean different
   courses. Stripping the letter prefix is **not** enough — `0433301` is
   Operating Systems but `A0433301` is Application Security. The course →
   skill map needs a canonical course id assigned deliberately, with each
   plan's code mapped onto it. Some syllabi state the mapping outright — see
   [Code equivalences](#code-equivalences-published-by-the-syllabi).

2. **Professional Ethics and the mathematics courses** sit inside the in-scope
   categories and will match few or no market skills. That is correct
   behaviour, not a pipeline failure. Physics and Chemistry were dropped
   outright — see Scope.
